# PIM-2
Este repositorio serve para acompanhar e facilitar a criação do trabalho do segundo semestre de ADS da unip. O projeto integrado multidisciplinar ou PIM.
Temos como objetivo desenvolver e documentar um sistema que tenha como funcionalidade permitir que o Barbeiro/Dono consiga organizar sua agenda de serviços além de permitir que o mesmo visualize seu estoque de produtos e gerencie seus clientes cadastrados no sistema. O sistema deve permitir ao Cliente se cadastre, realize login, agende serviços ou desmarques serviços. 
Tudo em torno de facilitar e resolver a agenda do nosso cliente o barbeiro
